### Task 3: Figure movement animation — tile-by-tile token travel

**Files:**
- Modify: `packages/client/src/board3d.ts`
- Modify: `packages/client/src/main.ts` (call `board3d.handleEvents(events)`)

**Interfaces:**
- Consumes: `FormattedEvent` (from `@laspoly/shared` protocol), `tileXZ()`, `JAIL_POS` from shared
- Produces: `Board3D.handleEvents(events: FormattedEvent[]): void` — new public method

**Design:** The server emits `{ key: "moved", params: { player, tile, pos }, playerId }` events in the `events` array alongside each `state` message. The `update()` call sets the final resting position; we intercept `moved` events to drive a per-tile animation BEFORE `update()` sets the final position. We keep a per-player animation queue (array of tile indices to hop through) and drive it via the Babylon scene's `onBeforeRenderObservable`.

Key event keys that imply movement:
- `"rolled"` — doesn't move by itself, but `d1`, `d2` are available for dice display
- `"moved"` — params contain `pos` (final tile) and `playerId`; we animate hop-by-hop
- `"wentToJail"` / `"actionCardMoveJail"` — animate up, fly to jail cage centre (JAIL_POS=40)
- `"leftJail"` — animate out of cage to normal tile
- `"traveled"` — train animation: lift, hop to destination

The `update()` method now receives the post-animation final state. We detect position changes by comparing to a `prevPositions` map. If the animation is still in progress we skip teleporting; the animation's `onFinished` callback sets the final mesh position.

```typescript
  handleEvents(events: FormattedEvent[]) {
    for (const ev of events) {
      if (ev.key === "moved" && ev.playerId) {
        const destPos = Number(ev.params?.["pos"] ?? -1);
        if (destPos < 0) continue;
        const prevPos = this.prevPositions.get(ev.playerId) ?? -1;
        if (prevPos >= 0 && prevPos !== destPos) {
          this.enqueueMove(ev.playerId, prevPos, destPos);
        }
        this.prevPositions.set(ev.playerId, destPos);
      } else if ((ev.key === "wentToJail" || ev.key === "actionCardMoveJail") && ev.playerId) {
        const prevPos = this.prevPositions.get(ev.playerId) ?? -1;
        if (prevPos >= 0) {
          this.enqueueJailAnimation(ev.playerId, prevPos);
        }
        this.prevPositions.set(ev.playerId, JAIL_POS);
      }
    }
  }
```

- [ ] **Step 3: Add `enqueueMove()` — builds hop path around the board ring**

```typescript
  private enqueueMove(playerId: string, from: number, to: number) {
    const path: Array<[number, number]> = [];
    // Board has 40 positions (0-39); JAIL_POS=40 is off-ring
    const RING = 40;
    let cur = from;
    // Always advance forward (positions increase modulo 40)
    while (cur !== to) {
      cur = (cur + 1) % RING;
      path.push(tileXZ(cur));
    }
    if (path.length === 0) return;
    const existing = this.moveQueues.get(playerId) ?? [];
    this.moveQueues.set(playerId, [...existing, ...path]);
    if (!this.moveAnimating.has(playerId)) {
      this.driveAnimation(playerId);
    }
  }
```

```typescript
  private driveAnimation(playerId: string) {
    const mesh = this.tokenMeshes.get(playerId);
    if (!mesh) { this.moveAnimating.delete(playerId); return; }

    const queue = this.moveQueues.get(playerId);
    if (!queue || queue.length === 0) {
      this.moveAnimating.delete(playerId);
      return;
    }

    this.moveAnimating.add(playerId);
    const [targetX, targetZ] = queue.shift()!;
    this.moveQueues.set(playerId, queue);

    const startX = mesh.position.x;
    const startZ = mesh.position.z;
    const startY = mesh.position.y;
    const HOP_DURATION = 120; // ms per tile
    const HOP_HEIGHT = 0.5;   // arc peak
    let elapsed = 0;
    let lastTime = performance.now();

    const obs = this.scene.onBeforeRenderObservable.add(() => {
      const now = performance.now();
      elapsed += now - lastTime;
      lastTime = now;
      const t = Math.min(elapsed / HOP_DURATION, 1);
      mesh.position.x = startX + (targetX - startX) * t;
      mesh.position.z = startZ + (targetZ - startZ) * t;
      // Parabolic arc
      mesh.position.y = startY + HOP_HEIGHT * 4 * t * (1 - t);

      // Update label position
      const lbl = this.tokenLabels.get(playerId);
      if (lbl) lbl.position.set(mesh.position.x, mesh.position.y + 0.8, mesh.position.z);

      if (t >= 1) {
        this.scene.onBeforeRenderObservable.remove(obs);
        mesh.position.set(targetX, 0.35, targetZ);
        if (lbl) lbl.position.set(targetX, 1.1, targetZ);
        // Chain next hop
        this.driveAnimation(playerId);
      }
    });
  }
```

### Task 4: 3D dice + dice cup animation

**Files:**
- Modify: `packages/client/src/board3d.ts`

**Interfaces:**
- Consumes: `FormattedEvent` with `key === "rolled"`, `params.d1`, `params.d2`; OBJ assets `rounded-dice.obj`, `DiceCup.obj`
- Produces: `Board3D.handleEvents()` extended to handle `"rolled"` event; dice cup + two dice visible near the board; roll animation on `"rolled"` event

**Design (inspired by DiceCup.java):**
- On scene init, load `DiceCup.obj` and `rounded-dice.obj` (the same obj for both dice, positioned apart).
- Die faces: Babylon dice OBJ is a rounded cube. We orient it by rotating to show the correct face:
  - face 1 up: Rx=0, Ry=0, Rz=0 (default — 1 faces up)
  - face 2 up: Rx=90
  - face 3 up: Rz=-90
  - face 4 up: Rz=90
  - face 5 up: Rx=-90
  - face 6 up: Rx=180
  (This may need tuning based on the actual OBJ; if orientation is wrong, adjust rotations. A fallback DynamicTexture label on the die surface shows the number.)
- Animation sequence (reproducing DiceCup.java's `playAnimation()`):
  1. Cup lifts up (Y+1.5 over 300 ms), shakes (±0.2 rotation over 400 ms × 3 cycles), cup descends (300 ms).
  2. Cup becomes transparent, dice settle with correct face rotations, a short settle bounce (Y+0.2 then back, 100 ms).
  3. Small "d1 + d2 = X" floating label appears for 2 s then fades.
- Use per-frame observable (same pattern as driveAnimation) or Babylon `Animation` objects.

```typescript
  /** Rotate a die mesh so the given face value faces up.
   *  For rounded-dice.obj: 1=top (default), 6=bottom, 2=front(-z), 5=back(+z), 3=right(+x), 4=left(-x).
   *  Adjust if the OBJ has a different default orientation.
   */
  private orientDie(mesh: AbstractMesh, face: number) {
    const PI = Math.PI;
    const H = PI / 2;
    switch (face) {
      case 1: mesh.rotation.set(0, 0, 0); break;
      case 2: mesh.rotation.set(H, 0, 0); break;
      case 3: mesh.rotation.set(0, 0, -H); break;
      case 4: mesh.rotation.set(0, 0, H); break;
      case 5: mesh.rotation.set(-H, 0, 0); break;
      case 6: mesh.rotation.set(PI, 0, 0); break;
    }
  }
```

```typescript
    let elapsed = 0;
    let lastTime = performance.now();
    let shakeCount = 0;

    // Hide dice under cup during animation
    if (die1) die1.position.y = -1;
    if (die2) die2.position.y = -1;

    const obs = this.scene.onBeforeRenderObservable.add(() => {
      const now = performance.now();
      const dt = now - lastTime;
      lastTime = now;

      if (phase === "lift") {
        elapsed += dt;
        const t = Math.min(elapsed / 300, 1);
        cup.position.y = baseY + LIFT * t;
        cup.rotation.z = Math.sin(t * Math.PI * 2) * SHAKE_AMP * 0.5;
        if (t >= 1) { elapsed = 0; phase = "shake"; }

      } else if (phase === "shake") {
        elapsed += dt;
        const t = elapsed / (100 * SHAKE_CYCLES);
        cup.rotation.z = Math.sin(t * Math.PI * 2 * SHAKE_CYCLES) * SHAKE_AMP;
        if (elapsed >= 100 * SHAKE_CYCLES * 4) { elapsed = 0; phase = "descend"; }

      } else if (phase === "descend") {
        elapsed += dt;
        const t = Math.min(elapsed / 300, 1);
        cup.position.y = baseY + LIFT * (1 - t);
        cup.rotation.z = 0;
        if (t >= 1) { elapsed = 0; phase = "settle"; }

      } else if (phase === "settle") {
        // Cup descended — show dice with correct orientations
        if (die1) {
          const cx = cup.position.x;
          const cz = cup.position.z;
          die1.position.set(cx - 0.25, 0.2, cz - 0.1);
          die2 && die2.position.set(cx + 0.25, 0.2, cz + 0.1);
          this.orientDie(die1, d1);
          if (die2) this.orientDie(die2, d2);
        }
        // Bounce settle
        elapsed += dt;
        const bounce = Math.abs(Math.sin(elapsed / 80 * Math.PI)) * 0.15 * (1 - Math.min(elapsed / 300, 1));
        if (die1) die1.position.y = 0.2 + bounce;
        if (die2) die2.position.y = 0.2 + bounce;
        if (elapsed >= 400) {
          // Show result label
          this.showDiceResultLabel(d1, d2, cup.position.x, cup.position.z);
          this.scene.onBeforeRenderObservable.remove(obs);
          this.diceAnimating = false;
        }
      }
    });
  }
```

```typescript
      const count = Math.floor(remaining / d);
```
