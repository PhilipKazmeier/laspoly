# LasPoly

LasPoly is a network-enabled, multi-client game in the style of Monopoly. 

  - Program consists of more than one instance of the game
  - Up to 4 players per game
  - Playing the game over the network
  - 3-Dimensional game field
  - Chat with the other players during the game

This program is part of a subject called ["Labor für Software-Projekte und Project Skills"] at the university [HS Heilbronn]. It is the sequel of the subject [Projektmanagement und Tools des SW Engineering].

### Installation

You need Java installed globaly at version 8u40 and higher. You also need IntelliJ installed. Then download the the project and import it into IntelliJ. Then run the class Server once and after that run the class Main. Jar-File will be added in future releases.
