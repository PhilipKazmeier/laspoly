Get the client

Download one launcher for your system. It pulls the game, Java 21, and JavaFX automatically — nothing to configure.

Windows run.bat Double‑click after download (don’t open run.ps1 — Windows shows that in Notepad) Mac / Linux run.sh chmod +x run.sh && ./run.sh
Advanced: download LasPoly.jar only

If you already have Java 21 + OpenJFX set up, you can run the jar directly. Everyone else should use the launcher above.

LasPoly.jar

How a round works

  1. 1 Run your launcher — the game window opens and connects to this server.
  2. 2 Someone creates a table in the lobby; everyone else joins it.
  3. 3 Host hits start when the table is full.

Desktop only (JavaFX 3D). Server restarts clear open tables.
