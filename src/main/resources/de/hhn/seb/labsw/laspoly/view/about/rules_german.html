Überblick

Spielvorbereitung

Zu Beginn des Spieles erhält jeder Spieler 1300 Las Poly Dollar (LPD).

Der Spielablauf

  1. Der Spieler der beginnt, wird zufällig vom Spiel bestimmt.
  2. Wer an der Reihe ist, kann bevor er würfelt noch Gebäude errichten oder Tauschangebote erzeugen.
  3. Dann wird gewürfelt und die Spielfigur wird in Pfeilrichtung um die Summe der Augenzahlen beider Würfel bewegt. Es ist möglich, dass mehrere Spielfiguren auf einem Feld stehen. Je nachdem, auf welchem Feld Sie bei Ihrem Zug landen, unterscheidet sich die Vorgehensweise wie grob im Folgenden beschrieben. Details sind weiter unten im jeweils zugehörigen Kapitel aufgeführt.
    • Landen Sie auf einem unverkauften Grundstück, so haben Sie die Chance, dieses zu kaufen. In diesem Fall wird der Grundstückswert von Ihrem Konto auf die Bank überwiesen.
    • Landen Sie auf einem verkauften Grundstück, müssen Sie dem Eigentümer Miete bezahlen. Diese spezifiziert die entsprechende Grundstückskarte. Bei Straßen hängt die Miete von der Position der Straße auf dem Grundstück und von den Gebäuden ab, die auf der Straße errichtet sind. Bei Attraktionen gibt es andere Methoden zur Berechnung der Miete. Diese sind der jeweiligen Grundstückskarte zu entnehmen. Ein mit einer Hypothek belastetes Grundstück bringt keine Miete ein.
    • Landen Sie auf dem Casino, müssen Sie Casinosteuern bezahlen.
    • Landen Sie auf dem Feld “Gehen Sie in das Gefängnis”, so wird Ihre Spielfigur sofort ins Gefängnis bewegt und Sie dürfen keine weiteren Spielaktionen ausführen.
    • Bewegt sich Ihre Figur bei Ihrem Zug über das Startfeld, bekommen Sie 200 LPD überwiesen. Landen Sie direkt auf dem Startfeld, so bekommen Sie sogar den doppelten Betrag (400 LPD).
    • Bei Aktionsfeldern müssen eine Aktionskarte ziehen und gegebenenfalls die Aktion der Karte ausführen.
    • Auf dem Frei-Parken-Feld dürfen Sie sich ausruhen und müssen keine Aktion ausführen.
    • Man kann von einem Bahnhof zu einem anderen Bahnhof reisen.
  4. Sobald Sie alle Straßen einer Farbgruppe besitzen, dürfen Sie auf diesen Häuser, Hotels oder Fabriken bauen.
  5. Wenn Sie einen Pasch würfeln, führen Sie Ihren Spielzug ganz normal durch und Sie dürfen danach noch ein weiteres Mal würfeln.
  6. Das Spiel wird solange fortgesetzt, bis nur noch ein Spieler übrig ist. Dieser Spieler ist der Gewinner.

Im Einzeln

Grundstücke kaufen

Es gibt 3 verschiedene Arten von Grundstücken: Straßen, Bahnhöfe, Attraktionen. Sobald Sie ein Grundstück gekauft haben, erhalten Sie die zugehörige Grundstückskarte. Ab dem Kauf eines Grundstückes erhalten Sie Miete von Spielern, die auf ihrem Grundstück landen. Während Ihr Grundstück mit einer Hypothek belastet ist, können Sie keine Miete einnehmen (Mehr dazu unter “Hypothek aufnehmen”). Besitzen Sie alle Straßen der selben Farbgruppe und haben Sie auf keinem dieser Straßen Gebäude errichtet, so verdoppelt sich die Grundstücksmiete für vorbeikommende Spieler.

Attraktionen

Attraktionen sind Grundstücke werden genauso verkauft wie Straßen. Es gibt die Attraktionen “Riesenrad” und “Zirkus”. Jede der Attraktionen kostet 150 LPD. Der Wert der Miete jedoch ist abhängig von der gewürfelten Augenzahl, mit welcher ein Mitspieler darauf landet. Besitztein Spieler eine der beiden Attraktionen, so beträgt die Miete den 4-fachen Wert der gewürfelten Augenzahl. Besitzt ein Spieler beide Attraktionen, so beträgt die Miete den 10-fachen Wert der gewürfelten Augenzahl in LPD.

Bahnhöfe

Die Bahnhöfe werden genauso verkauft wie Straßen. Jeder Bahnhof kostet 200 LPD. Wenn Sie auf dem Bahnhof eines anderen Spielers landen, zahlen Sie ihm die Miete. Die Miete ist abhängig von der Anzahl der Bahnhöfe, die ein Spieler besitzt. Miete für einen Bahnhof beträgt 50 LPD, für jeden weiteren Bahnhof den ein Spieler besitzt wird die Miete verdoppelt.

Zugreisen

Wenn Sie auf einem Bahnhof landen, können Sie mit dem Zug zu einem anderen Bahnhof reisen. Da es insgesamt vier Bahnhöfe gibt, können Sie entsprechend zu drei verschiedenen Bahnhöfen reisen. In Laufrichtung gesehen kostet die Reise pro Bahnhof 75 LPD .Das Geld bekommt die Bank. Ist der Startbahnhof Ihrer Reise bereits verkauft, so zahlen Sie vor Ihrer Reise noch die Miete für diesen Bahnhof. Für den Zielbahnhof fällt jedoch keine Miete an. Bei Reisen zwischen Bahnhöfen, zwischen denen das Startfeld liegt, bekommen Sie kein Geld für das Überschreiten dieses Felds.

Gebäude bauen

Grundsätzlich kann ein Spieler nur Gebäude auf Straßen errichten, wenn er alle zugehörigen Straßen der selben Farbgruppe besitzt. Außerdem darf nur Gebäude bauen, wer an der Reihe ist. Da es in jeder Reihe Farbgruppen mit nur einer einzigen Straße gibt, kann man als Eigentümer dieses Grundstücks sofort beginnen, Gebäude darauf zu errichten.

Häuser bauen

Der Preis eines Hauses steht auf jeder Grundstückskarte. Häuser dürfen nur im einem gebaut werden, wenn sich auf der zu bebauenden Straße nicht schon ein Hotel oder eine Fabrik befindet. Häuser müssen gleichmäßig gebaut werden: Sie müssen also erst auf jeder Straße einer Farbgruppe ein Haus errichten, bevor Sie ein zweites auf einer Straße bauen können. Sie dürfen so viele Gebäude auf einmal bauen, wie Sie sich leisten können. Jedoch dürfen Sie keine Häuser auf Straßen bauen, wenn eine oder mehrere Straßen dieser Farbgruppe mit einer Hypothek belastet ist. Die Miete einer Straße erhöht sich mit dem Bauen von Häusern. Details zu den Mieten sind der jeweiligen Grundstückskarte zu entnehmen.

Hotels bauen

Ein Spieler kann ein Hotel auf eine Straße bauen, wenn sich auf einer Straße zuvor vier Häuser befinden. Beim Bau eines Hotels werden die Häuser entfernt und dafür ein Hotel errichtet. Der Preis eines Hotels befindet sich auf der Grundstückskarte einer Straße. Die Miete einer Straße erhöht sich mit dem Bauen eines Hotels.

Fabriken bauen

Fabriken stellen eine Alternative zum Bau von Häusern und Hotels dar. Fabriken können nur gebaut werden, wenn sich auf einer Straße keine anderen Gebäude befinden. Sie müssen sich also entscheiden, ob sie auf einer Straße eine Fabrik bauen möchten, oder ob sie Häuser und Hotels errichten wollen. Fabriken haben im Gegensatz zu Häusern und Hotels die Eigenschaft, dass Sie einen bestimmten Betrag (zu finden auf der Grundstückskarte der Straße) von der Bank erhalten, wenn Sie mit Ihrer Spielfigur direkt auf der Straße mit der Fabrik landen. Dies gilt nur, wenn Sie selbst Inhaber der Straße sind. Wenn Spieler auf Ihre Straße mit der Fabrik kommen, so entfällt für diese die Zahlung einer Miete.

Casino

Das Casino ist ein Spezialfeld. Landet man mit einem Pasch auf dem Casino, so erhält man ein Viertel des Casino-Vermögens. Eine Ausnahme bildet der 6er-Pasch. Kommt man mit zwei Sechsen auf das Casino, gewinnt man den Jackpot! Das ist jeweils die Hälfte des im Casino vorhandenen Vermögens.

Casino-Steuerfeld

Landen Sie auf einem der Casino-Steuerfelder, müssen Sie dem Casino den angegebenen Betrag überweisen.

Das Gefängnis

Es gibt drei Möglichkeiten, ins Gefängnis zu kommen. Wenn Sie in einem Zug drei mal in Folge einen Pasch würfeln oder wenn Sie auf dem Spezialfeld “Gehen Sie ins Gefängnis” landen oder wenn Sie in einer Aktionskarte dazu aufgefordert werden, müssen Sie ins Gefängnis. Sollten Sie mit Ihrem dritten Pasch über Los gekommen sein, erhalten Sie kein Geld. Sie müssen aber gegebenenfalls Miete bezahlen. Im nächsten Zug dürfen Sie dann vom Gefängnis aus würfeln. Haben Sie einen Pasch gewürfelt, kommen Sie frei und dürfen sofort um die gewürfelte Augenzahl weiterziehen. Sollten Sie nach drei Zügen keinen Pasch gewürfelt haben, müssen Sie eine Strafe von 50 LPD an die Bank bezahlen und ziehen anschließend im selben Zug weiter. Natürlich kann man vor der 3. Runde sich aus dem Gefängnis herauskaufen.

Ihr Vermögen

Kein Geld mehr

Im Verlauf des Spiels kann es passieren, dass Ihr Vermögen knapp wird. Sobald Sie ein einziges Mal zahlungsunfähig sind, scheiden Sie aus dem Spiel aus. Aus diesem Grund sollten Sie versuchen, vorrausschauend zu spielen! Vergewissern Sie sich vor dem Kauf von Grundstücken und Gebäuden, beim akzeptieren von Tauschangeboten etc. immer, dass Sie genug Vermögen haben, um die Zahlung auszuführen!

Tauschen und Verkaufen

Unbebaute Straßen, Bahnhöfe und Attraktionen dürfen jederzeit mit anderen Spielern zum Tausch angeboten werden. Zusätzlich können auch bestimmte Geldbeträge zu dem Tausch hinzugefügt werden. Als Gegenlsitung wird ebenfalls ein Gebäude oder auch Geld verlangt. Eine Straße darf aber nicht getauscht werden, wenn sich auf mindestens einer der Straßen der Farbgruppe ein Gebäude befindet. Diese Gebäude müssen davor erst verkauft werden. Tauschangebote können vorbereitet weden, während andere Spieler an der Reihe sind. Sie können einem anderen Spieler aber erst ein Tauschangebot senden, wenn Sie an der Reihe sind. Außerdem kann ein Tauschangebot nur zustandekommen, wenn der anbietende Tauschpartner gerade an der Reihe ist.

Gebäude werden zum halben Preis an die Bank zurückverkauft. Häuser werden genauso gleichmäßig verkauft, wie sie gebaut wurden. Beim Verkaufen eines Hotels würde der Spieler den halben Preis für das Hotel und den halben Preis für die 4 Häuser erhalten. Es ist auch möglich, ein Hotel in 4 Häuser zurück zu verwandeln.

Desweiteren kann für die Hälfte des Kaufpreises ein Grundstück an die Bank zurück verkauft werden. Beim Verkauf von Straßen an die Bank müssen zuerst alle Gebäude verkauft werden.

Hypothek aufnehmen

Um wieder an Geld zu kommen, können Sie eine Hypothek auf Ihr Grundstück aufnehmen. Dabei wird die Grundstückskarte umgedreht und Sie erhalten von der Bank den Hypothekenwert Ihres Grundstücks. Um Hypotheken auf Straßen zu bekommen, müssen zuerst alle Gebäude auf der Straße verkauft werden. Während ihr Grundstück belastet ist, fällt für andere Spieler keine Miete auf diesem Grundstück an.

Hypothek zurückzahlen

Um eine Hypothek aufzulösen, bezahlen Sie der Bank den ursprünglichen Betrag der Hypothek zurück plus 10% Zinsen.
